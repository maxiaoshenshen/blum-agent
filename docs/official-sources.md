## 维护规则

1. 新增事实前先确认来源属于 Blum 官方域名。
2. 摘要只保留跨市场相对稳定的事实；价格、库存、交期和授权关系不进入本地知识。
3. 型号、兼容性、孔位、承重、电气与安全问题始终标记为复核项。
4. 每季度检查链接有效性；产品发布或中国订购资料更新时立即复核。
5. 链接失效时保留安全降级：产品目录、配置器和官方联系渠道。
